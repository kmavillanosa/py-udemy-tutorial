# Introduction

Basic introduction to Python with simple arithmetic operations and print statements.

## Concepts Covered

- Variable assignment
- Basic arithmetic operations
- Formatted string output using f-strings

## Code Example

```python
a = 100
b = 200
c = a + b
print(c)

print(f"The sum of {a} and {b} is {c}")
```

## Running the Code

```bash
python ./section-one/1introduction.py
```

## Output

```
300
The sum of 100 and 200 is 300
```
